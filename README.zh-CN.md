# aiping · 本地信号 + Codex AI

项目介绍、原作者署名、相对上游的改动、非商业用途及权利联系说明见 [README](README.md)。本文件补充操作与构建细节。

这是基于 Danrui Meng 的 lolPing 0.5.1 及现有 Codex 修改版制作的精简版本。

保留全部 11 种普通信号、轮盘、全局快捷键、多屏定位、动画音效、透明穿透覆盖层、暂停/恢复、全屏暂停、托盘与中文设置。

AI 模式保留问号解释、全力进攻讨论、需要视野/敌方视野记录、请求协助教学。截图立即开始，发送按接收顺序排队；分析由绑定聊天按独立任务编号处理。程序通知不触发截图。发送未确认不自动重试，记录真实保存后才提示保存成功。

已经删除房间、成员、LAN/互联网中继、房间加密协议、表情轮盘及导入资源、自动更新实现和专用依赖。AI 连接层保持原接口。

## 矩形框选与自由指向

AI 模式开启时，连续短按两次左 Alt 进入框选。等待固定画面完成后，用左键拖出矩形；可以拖动选区或四个角调整。随后在任意位置（包括另一块显示器）按住 Alt 拖动轮盘，松手发信号。图标和音效保持在鼠标起点，不移动到选区中心。Esc、右键或再次双击左 Alt 取消；发送后自动退出框选。

有选区时，以整个框内为分析主体，全图补充上下文。无选区时，以信号附近为分析重点，同屏其他区域同样作为参考。两种模式均保存全图与局部图。选区使用进入框选时固定的原图，之后页面变化不会改变待发送内容。

一次选区限一块显示器；可以在其他显示器发信号。普通 ping 的原快捷键保持不变；框选模式下的轮盘使用 Alt。Alt+Tab、Alt+F4、长按、带其他按键的组合不触发框选。双击需要每次按住不超过 220 ms、两次松开间隔不超过 350 ms。当前实机验证为 Windows 双屏 100% 缩放。

## 连接 Codex 桌面版

1. 打开并登录 Windows Codex 桌面版，准备一个接收聊天。
2. 安装或解压本程序；首次运行直接打开「Codex 连接」。点击「连接 Codex」。
3. 选择接收聊天，点击「连接并启用 AI」。显示「已连接」及正确聊天名称后即可发信号。

不需要另装 Node、填写 API Key、配置环境变量或修改 Codex hooks。使用 Codex 已有的登录、模型及权限设置；费用也沿用 Codex 本身。找不到目标时，在 Codex 打开该聊天、发送一句消息后刷新。

选择会保存，应用重启自动恢复。更换接收聊天立即生效；已排队任务保留原目标，不会串到新聊天。应用自带独立连接进程，已提交的分析仍可在主界面退出后回传。截图默认保存在应用数据目录 captures，笔记与结果在 codex/tasks。`LOLPING_CAPTURE_DIR` 仍可指定截图目录。

状态提醒监听全部本机用户聊天；内部子智能体不分别播放完成提示。完成依据真实会话结束记录，不依赖个人提示音脚本。首次连接不补播历史完成和旧提问卡片。Codex 的权限审批保持其原有规则，不自动批准操作。

旧的 `LOLPING_CODEX_BINDING` 连接仍可使用；通过界面连接后，不会被旧启动环境变量覆盖。

旧设置的历史字段在磁盘上保留，渲染界面只接受当前功能的字段。已有截图、笔记、自定义历史资源和任务结果不删除。

## 限制

发送队列在内存中；没有增加崩溃或退出恢复。关闭前应等待已接收任务发送完毕。AI 连接失效时普通信号仍可用，AI 操作会提示失败或发送未确认。

本轮实机验收在 Windows 双屏 100% 缩放环境完成；其他缩放通过坐标单元测试覆盖，尚未做真实混合缩放验收。保留 macOS 原实现，但本轮未在 macOS 实机验证。

一键接入目前支持 Windows，实测 Codex 桌面版 26.1007.2314.0。使用桌面兼容接口，Codex 升级后需要复测；尚未在另一台干净 Windows 机器上运行安装向导。自动软件更新保持关闭，版本通过安装包手动升级。
